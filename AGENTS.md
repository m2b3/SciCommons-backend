# Repository instructions

These instructions apply to work performed in the SciCommons backend repository.

## Final-response logging

- At the end of every backend operation, append the exact final assistant response to the repository-root `codexOutput.md`.
- Precede each response with a heading containing the current date, time, and UTC offset.
- Append chronologically; do not replace or rewrite earlier entries.
- Do not log backend-operation responses to the sibling frontend repository.
